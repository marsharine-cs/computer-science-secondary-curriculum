# Introduction to Python — Grades 9–12

This directory presents the public portfolio view of an original **36-lesson, 7-unit secondary Python curriculum** developed by **Marsharine A. Simpson**.

The course is designed for students with no prior coding experience and moves from precise instructions and simple output toward structured programs using decisions, loops, functions, and data.

> **Public portfolio only:** This directory contains selected materials intended to demonstrate curriculum architecture, technical accuracy, instructional design, assessment thinking, and teacher support. The complete editable course is maintained privately.

## Instructional approach

The course is built around several recurring principles:

- **Working programs matter more than isolated syntax recall.**
- **Debugging is a core programming skill and is taught from Unit 1.**
- **Readable code and purposeful documentation are part of program design.**
- **Students progress from guided examples toward increasingly independent programming tasks.**
- **Assessment asks students to apply concepts, explain behavior, debug errors, and make design decisions.**
- **Later units connect Python syntax to broader algorithmic thinking and pseudocode.**

The finalized lesson is the source of truth for all associated slides, student materials, labs, assessments, answer keys, and teacher resources.
