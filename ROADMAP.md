# Computer Science Secondary Curriculum — Development Roadmap

This roadmap tracks the ongoing development of the **Computer Science Secondary Curriculum** project.

The repository is designed to grow across multiple programming languages, computer science topics, and secondary grade levels.

## Development Workflow

Each instructional unit follows this process:

**Lesson Development → Lesson Finalization → Companion Material Development → Alignment Review → Quality Assurance → Portfolio Review → Public Sample Release**

The finalized lesson serves as the source of truth for all accompanying materials.

## Public Repository Releases

Only selected, reviewed portfolio samples will be published in this repository.

Public releases may include:

* Course overviews
* Selected lesson excerpts
* Selected slide samples
* Coding examples
* Student activities
* Sample labs
* Selected assessment examples
* Curriculum design documentation
* Project-development notes

Complete editable curriculum packages, full answer keys, protected assessments, and other proprietary teacher resources are maintained separately.

## Long-Term Project Direction

The long-term goal is to build a growing collection of coherent secondary computer science courses and instructional resources that demonstrate:

* strong curriculum architecture
* standards-informed instructional design
* accessible programming instruction
* authentic coding practice
* assessment alignment
* debugging and problem-solving pedagogy
* differentiation
* teacher support
* project-based learning

## Status Key

**Active Development** — currently being written or built
**Alignment Review** — materials are being checked against finalized lesson content
**Quality Assurance** — instructional and technical review in progress
**Public Sample Ready** — approved for inclusion in the public repository
**Planned** — scheduled for future development
